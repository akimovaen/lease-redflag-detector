Read a whole lease and list the clauses that are risky for the landlord (red flags), each with its type and the clause quoted verbatim, together with the main terms: parties, premises, term, rent and indexation.

Use it when the lawyer asks to check a lease for risks. It calls a model and costs money, so call it once per lease, not to answer a question about one clause (read that section instead). Needs a lease id from find_leases.

Red flag types: landlord_repairs, service_charges_limited, tenant_break_option, indexation_limited, sublease_permitted.
